# Repository instructions

This repository contains workflow instructions, agent roles and skills.

- Make only the requested changes. Preserve role frontmatter, installation paths and third-party attribution unless the request changes them.
- Read the relevant source in `roles/` and `skills/` before editing it. Keep `SETUP.md` and the README setup prompt consistent with installation changes.
- Do not install the workflow or change user-level agent configuration when working on this repository. `SETUP.md` is followed only when the user asks to set up the workflow.
- Run `git diff --check` and inspect the final diff before handing back. Do not claim installation or functional validation unless it was actually run.
