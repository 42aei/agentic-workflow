# Agentic workflow

## Before the workshop

[Install GitHub Copilot CLI](https://docs.github.com/en/copilot/how-tos/set-up/install-copilot-cli) and sign in with a GitHub account that has Copilot access. Start `copilot` and use `/login` if prompted.

Paste this into Copilot CLI:

```text
Read https://github.com/42aei/agentic-workflow/blob/main/SETUP.md and
help me set up the workshop prerequisites.
```

## Optional

[GitHub Copilot Desktop App](https://github.com/features/copilot). The workflow is not yet verified in Desktop. Use CLI for the workshop.
